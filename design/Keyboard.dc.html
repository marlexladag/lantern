Keyboard
The app is drivable without a mouse. Every shortcut below is part of the design, not a later addition.
Global
⌘KQuick-open any connection, table or saved query
⌘TNew tab
⌘WClose tab
⌘1–9Jump to tab
⌘EToggle SQL editor
⌘RRefresh table / re-run query
Grid
↑↓←→Move selection
⇥Next cell · ⇧⇥ previous
⏎Edit cell · ⏎ again commits to the change set
escAbandon the edit
⌘NInsert row
⌘⌦Mark row deleted
⌘FFilter rows
Editor
⌘RRun
⌘⇧RRun selection
⌘.Cancel the running query
⌘⇧FFormat SQL
⌘/Toggle comment
Changes
⌘SCommit staged changes
⌘⇧PPreview generated SQL
⌘ZUndo the last staged change
